Database Google Sheets
Status: Mode Lokal (data masih tersimpan di perangkat ini saja).
Langkah 1 · Siapkan Google Sheets
Buka project Apps Script (dari script.google.com atau Google Sheet → Ekstensi → Apps Script) → hapus isi Code.gs → tempel kode dari tombol di bawah → ganti PIN_RAHASIA dengan 6 angka → Simpan → jalankan fungsi persiapan sekali (beri izin) → Deploy → Deployment baru → Aplikasi web (Akses: Siapa saja) → salin URL /exec.
Langkah 2 · Sambungkan aplikasi ini
Bagikan Link Mode Lokal (Tanpa Akses ke Database Cloud):
Koperasi lain tetap bisa memakai aplikasi ini dengan link database kosong (Mode Lokal). Data mereka tersimpan mandiri di perangkat masing-masing dan tidak tercampur dengan database KDKMP Salamnunggal.
Link Otomatis untuk HP / Tablet Internal (Tersambung Database):
Khusus tim internal toko Anda: begitu diklik, perangkat langsung tersambung ke database bersama yang sama. PIN tidak ikut di link, beri tahu PIN ke petugas secara terpisah (jangan di grup).
PIN login diminta saat aplikasi dibuka. Tempel URL Web App Google Apps Script (.../exec), pastikan Kode Toko / Gerai sama di semua perangkat, lalu tekan Hubungkan & Sinkronkan.
